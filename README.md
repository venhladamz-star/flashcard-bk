# 📚 Flashcard - Học từ vựng & Ngữ pháp

Ứng dụng Flashcard chạy hoàn toàn bằng **HTML + CSS + JavaScript**, giúp học từ vựng và ngữ pháp với giao diện hiện đại, hỗ trợ đồng bộ dữ liệu bằng Firebase.

## ✨ Tính năng

### 📖 Học từ vựng
- Tạo bộ flashcard từ dữ liệu Excel, Word hoặc Google Sheets.
- Lật thẻ để học.
- Đánh dấu:
  - ✅ Đã thuộc
  - ❌ Chưa thuộc
- Ôn lại các từ chưa thuộc.
- Trộn ngẫu nhiên thứ tự từ.
- Phát âm bằng Text-to-Speech hoặc file MP3.

### 📝 Kiểm tra
- Chế độ trắc nghiệm.
- Chế độ tự luận.
- Chấm điểm ngay sau mỗi câu.
- Thống kê kết quả học.

### 📚 Ngữ pháp
- Đọc bài ngữ pháp dạng Markdown.
- Admin có thể tạo, sửa và xóa bài.
- Hỗ trợ bảng, danh sách, tiêu đề và code block.

### 🌐 Tham khảo
- Chia sẻ bộ từ vựng công khai.
- Người dùng có thể học trực tiếp các bộ từ do Admin đăng.

### ☁️ Đồng bộ dữ liệu
- Đăng nhập Google.
- Đồng bộ bằng Firebase Firestore.
- Lưu dữ liệu giữa nhiều thiết bị.

### 🎨 Giao diện
- Dark Mode / Light Mode.
- Responsive:
  - 📱 Điện thoại
  - 📲 Máy tính bảng
  - 💻 Laptop/Desktop
